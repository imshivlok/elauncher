Release Notes

Last updated: Today

Performance Improvements (WASM-GC)

- Introduced experimental WebAssembly Garbage Collection (WASM-GC) support. This significantly reduces stuttering and improves overall frame rates on modern browsers.

- Adjusted chunk rendering logic to prioritize blocks closest to the player, reducing initial load times when joining multiplayer servers.

Multiplayer Fixes

- Fixed an issue where WebSockets would drop connection prematurely on high-latency networks.

- Added enhanced skin rendering for players using custom Eaglercraft skin URLs.

- Voice chat stability improvements across major public instances.
